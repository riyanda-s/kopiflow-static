# KopiFlow implementation plan

1. Static Astro, strict TypeScript, Tailwind Vite integration. No adapter or backend.
2. Central business/theme/menu configuration; build-time validation. Original identity, local licensed photography, system fonts.
3. Reusable Astro presentation components; native dialogs and a small TypeScript controller for browser interactions.
4. Catalog-driven pricing: persisted cart contains selections, never trusted prices. Revalidate against the current catalog.
5. WhatsApp message generation with normalized numbers; demo contacts disabled. SVG QR produced at build time from configured domain.
6. Four main pages, privacy, QR print page, 404, sitemap and robots. Clearly fictional business data; no fabricated LocalBusiness claims.
7. Type check, lint, functional unit tests, desktop/mobile Playwright, dependency audit, production build and Lighthouse measurements.
8. Configuration, hosting, onboarding, QA and commercial handover documentation. No deployment or remote resources.
